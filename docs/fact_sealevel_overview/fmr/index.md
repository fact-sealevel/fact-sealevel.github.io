# FACTS-module-registry 

In this section, you'll find information about the FACTS-module-registry (FMR). This is the interface between the FACTS module ecosystem and [facts-experiment-builder](../feb/index.md) (FEB). To be used by FEB, a module must have a complete and correctly structured entry in FMR (ie. a 'module YAML' file in a directory named after the module).
