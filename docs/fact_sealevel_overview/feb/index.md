# FACTS-Experiment-Builder

In this section, you'll find information about the FACTS-experiment-builder (FEB) [package](https://github.com/fact-sealevel/facts-experiment-builder). This is a package developed for the FACTS framework. It offers command line interface (CLI) commands to configure FACTS experiments and generate experiment artifacts (`experiment-config.yaml` files) which are self-describing, complete specifications of an experiment, and experiment Docker Compose scripts, which are generated directly from experiment configuration files and enable the execution of a a FACTS experiment.
