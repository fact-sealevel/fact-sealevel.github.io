# FACTS Module

### FACTS module
A FACTS module models a physical process and produces a distribution of projections based on a set of inputs. FACTS modules can produces projections of temperature change given an emissions scenario, projections of global mean sea-level (GMSL) change due to physical processes such as land ice or land water storage change, projections of relative sea level (RSL) change associated with processes such as glacial isostatic adjustment and subsidence, and return levels of extreme sea level based on sea-level projections and historical tide gauge data. 

In FACTS2, all modules exist as stand-alone applications with associated GitHub repositories. If you would like to contribute a module to FACTS, see the [Module Contributor Guide](../module_contributor_docs/index.md).

FACTS modules interface with other tools in the FACTS ecosystem such as FEB through the FACTS-module-registry.
