# FACTS Module Contriutor Guide

Here you'll find an overview of contributing a module to FACTS, including links to detailed instructions for various steps of the process.

Most of the content assumes you already have a module partially developed, or already developed elsewhere and will be porting a version into the FACTS framework. 

## Step 1: Review the [module requirements](module_requirements.md) document

## Step 2: Create a repository for your module
We suggest using the [module template](https://github.com/fact-sealevel/module-template) available on the FACT-Sealevel GitHub organization.

## Step 3: Develop your module
For a step-by-step guide on building your module, see the module development [tutorial](build_facts_module_tutorial.md)
Steps:
- Update module name in the module repo
- Add module code
- Add README
- Push code to GitHub
- Test your module locally 

## Step 4: Add your module to the FACTS module registry
See the [tutorial](submit_module_to_fmr_tutorial.md) on submitting a module to the module registry.
Steps:
- Write module yaml
- Open PR in FMR repo
